# BlueStock FinTech Project 01 - Day 2: Data Transformation & Cleaning

## 📋 Day 2 Objectives

This day focuses on:
1. **Data Type Standardization** - Convert to optimal types (datetime, float, int, category)
2. **Missing Value Handling** - Imputation strategies per column type
3. **Outlier Detection** - Identify and handle anomalies in NAV data
4. **Date Normalization** - Ensure consistent datetime formats
5. **Categorical Encoding** - Prepare fund house, category, risk grade for analysis
6. **Feature Engineering** - Create derived metrics (daily returns, moving averages)
7. **Data Quality Report** - Before/after comparison

## 🎯 Deliverables

- `data_transformation.py` - Core transformation pipeline
- `data_cleaning.py` - Missing value, outlier, and anomaly handling
- `feature_engineering.py` - Derived metrics and enrichment
- `data_quality_report.py` - Profiling and validation reports
- Processed data in `data/processed/`
